Web Tasarım Dersi · 1. Hafta

Temel Kavramlar

İnternetin çalışma mantığını, web sitelerinin yapısını ve web geliştirme alanında kullanılan temel terimleri öğrenelim.

İnternet Adres ve Konum Sayfa Yapısı Geliştirici Rolleri Alan Adı Uzantıları

Bu ödevde internet ve web tasarımının temel yapı taşları açıklanmıştır. Konular, daha kolay okunabilmesi için başlıklara ayrılmıştır.

1 İnternet'in Temel Yapı Taşları

IP Adresi (Internet Protocol Address)

İnternete bağlı her bir cihazı (bilgisayar, sunucu, telefon vb.) tanımlayan sayısal etikettir.

DNS (Domain Name System)

İnsanların okuyabildiği alan adlarını (google.com gibi), bilgisayarların kullandığı IP adreslerine çeviren internetin telefon rehberidir.

Sunucu (Server)

Web sitelerini, dosyaları veya uygulamaları barındıran ve internet üzerinden gelen isteklere yanıt veren bilgisayardır.

HTTP (Hypertext Transfer Protocol)

Web tarayıcısı ile sunucu arasında web sayfası verilerinin nasıl aktarılacağını belirleyen iletişim kuralıdır.

HTTPS (Hypertext Transfer Protocol Secure)

HTTP'nin, tarayıcı ile sunucu arasındaki veri iletişimini şifreleyerek daha güvenli hâle getiren sürümüdür.

2 Web Sitesinin Adresi ve Konumu

Domain (Alan Adı)

Bir web sitesinin karmaşık IP adresi yerine kullanılan, akılda kalıcı ve kolay yazılabilen ismidir. Örnek: google.com.

URL (Uniform Resource Locator)

Bir web kaynağının (belirli bir sayfa, resim veya dosya) internetteki tam ve özel adresini gösterir.

WWW (World Wide Web)

İnternet üzerinde bulunan ve URL'ler aracılığıyla erişilebilen, birbirine bağlı web sayfaları ve içeriklerden oluşan sistemdir.

Hosting (Barındırma)

Bir web sitesinin dosya ve verilerinin internet üzerinden erişilebilir olması için sunucuda saklanması hizmetidir.

FTP (File Transfer Protocol)

Bir bilgisayar ile sunucu arasında dosya yüklemek veya indirmek için kullanılan ağ protokolüdür.

3 Web Sayfasının Yapısı ve Görünümü

HTML (Hypertext Markup Language)

Bir web sayfasının iskeletini; başlık, paragraf ve resim gibi temel içeriklerini oluşturan işaretleme dilidir.

Etiket (Tag)

HTML'de bir elementi tanımlamak için kullanılan, küçüktür ve büyüktür (< >) işaretleri arasındaki ifadelerdir. Örnek: <p> paragraf etiketi.

CSS (Cascading Style Sheets)

HTML ile oluşturulan web sayfasının renk, yazı tipi, yerleşim ve diğer görsel özelliklerini belirler.

JavaScript (JS)

Web sayfalarına butonlar, animasyonlar ve form kontrolleri gibi etkileşimli özellikler kazandıran programlama dilidir.

4 Web Geliştirici Rolleri ve Araçları

Front-end (Ön Yüz)

Bir web sitesinin kullanıcının tarayıcıda gördüğü ve etkileşimde bulunduğu arayüz kısmını geliştiren alandır.

Back-end (Arka Yüz)

Bir web sitesinin veritabanı, sunucu işlemleri ve iş mantığı gibi kullanıcı tarafından doğrudan görülmeyen bölümlerini geliştirir.

Full-stack (Tam Yığın)

Bir web projesinin hem front-end hem de back-end geliştirmesini yapabilen uzmanlık alanıdır.

Tarayıcı (Browser)

Google Chrome ve Firefox gibi web sayfalarını görüntülememizi ve onlarla etkileşim kurmamızı sağlayan yazılımlardır.

Editör (Kod Editörü)

HTML ve CSS gibi kodları yazmak, düzenlemek ve yönetmek için kullanılan programdır. Örnek: Visual Studio Code (VS Code).

WYSIWYG Editör

Kod yazmadan, sürükle-bırak gibi görsel araçlarla web sayfası oluşturmayı sağlayan editördür. “Ne Görürsen Onu Alırsın” anlamına gelir.
